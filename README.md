# 基于 STM32F103C8T6 的遥控平衡车项目

本项目是一套基于 STM32F103C8T6 的两轮自平衡车固件，包含车体控制器和手持遥控器两个独立的 Keil 工程。车体通过 MPU6050 获取姿态信息、编码器获取轮速，并使用串级 PID 实现平衡、前后运动和转向；遥控器通过 NRF24L01 在 2.4 GHz 频段发送摇杆和按键指令。

## 功能概览

- 基于 MPU6050 加速度计和陀螺仪的互补滤波姿态解算
- 角度环、速度环、转向环串级 PID 控制
- 双路编码器测速与双电机 PWM 驱动
- NRF24L01 无线遥控，支持遥测数据回传
- 0.96 英寸 OLED 显示运行状态、控制参数和遥测信息
- 蓝牙串口在线调节 PID 参数
- 本地按键或遥控器 K1 启停平衡控制
- 倾倒保护：车体倾角超过 +/-50 度时自动停止电机

## 车体控制原理

车体控制逻辑位于 `平衡车/User/main.c`：

1. TIM1 每 1 ms 进入一次中断。
2. 每 10 ms 读取 MPU6050，使用加速度计角度与陀螺仪积分角度进行互补滤波，得到车体倾角。
3. 角度环 PID 的输出作为双电机平均 PWM，维持车体竖直。
4. 每 50 ms 读取左右编码器，计算平均速度和差分速度。
5. 速度环 PID 的输出作为角度环目标值，实现前进和后退；转向环 PID 的输出作为左右轮 PWM 差值，实现转向。

```text
遥控器前后指令 -> 速度环 PID -> 角度环目标值 -> 角度环 PID -> 电机平均 PWM
遥控器转向指令 -> 转向环 PID -------------------------------> 电机差分 PWM
```

默认 PID 参数如下，实际使用时需要结合整车机械结构和重心进行调试：

| 控制环 | Kp | Ki | Kd | 输出范围 |
| --- | ---: | ---: | ---: | ---: |
| 角度环 | 5.00 | 0.10 | 5.00 | -100 ~ 100 |
| 速度环 | 2.00 | 0.05 | 0.00 | -20 ~ 20 |
| 转向环 | 4.00 | 3.00 | 0.00 | -50 ~ 50 |

## 无线通信

两个工程的 NRF24L01 配置保持一致：

| 参数 | 值 |
| --- | --- |
| 通信地址 | `11 22 33 44 55` |
| 工作频点 | 2402 MHz |
| 空中速率 | 2 Mbps |
| 发射功率 | 0 dBm |
| 有效载荷长度 | 32 字节 |
| 自动重传 | 间隔 250 us，最多 3 次 |

遥控器每 100 ms 发送一次控制数据。摇杆原始 ADC 值会被转换为 `-100 ~ 100`，并在中值附近设置死区。

### 控制报文

| 字节 | 内容 |
| --- | --- |
| 0 | 报文 ID：`0x00` 为仅发送控制，`0x01` 为请求遥测回传 |
| 1 | 左摇杆横向值 LH |
| 2 | 左摇杆纵向值 LV，用于前进/后退 |
| 3 | 右摇杆横向值 RH，用于左转/右转 |
| 4 | 右摇杆纵向值 RV，当前未使用 |
| 5 | 按键键码，K1 用于启停控制 |

### 遥测报文

遥控器按下 K9 可切换到请求遥测的模式。车体收到 `0x01` 报文后，会返回 ID 为 `0x02` 的数据包，包含左右 PWM、车体倾角和左右轮速度；遥控器 OLED 会显示这些数据及最近 10 次发送中的成功次数。

## 编译与烧录

1. 使用 Keil uVision 打开 `平衡车/Project.uvprojx`，编译并烧录车体控制器。
2. 使用 Keil uVision 打开 `遥控器控制/Project.uvprojx`，编译并烧录手持遥控器。
3. 在目标选项中确认器件为 `STM32F103C8`，下载接口使用 SWD。
4. 当前工程默认未生成 HEX 文件。如需导出，在 Keil 的 `Options for Target -> Output` 中勾选 `Create HEX File`。

## 使用步骤

1. 首次测试时将车体悬空或采取可靠支撑，确保轮子可以安全转动。
2. 确认电机、编码器、MPU6050、OLED 和两块 NRF24L01 已按原理图连接，且供电稳定。
3. 上电后观察车体 OLED 的角度、陀螺仪 Y 轴值和 PID 参数是否正常显示。
4. 让车体保持静止并接近竖直状态，使用车体 K1 或遥控器 K1 启动平衡控制。
5. 使用左摇杆纵向控制前进/后退，使用右摇杆横向控制转向。
6. 遥控器 OLED 的 `Sig` 表示最近 10 次发送中的成功次数；按 K9 可切换是否显示车体遥测信息。

## PID 标定建议

不同电机、轮胎、供电电压、车架重心和 MPU6050 安装角度都会改变控制参数。建议按以下顺序调试：

1. 禁用速度环和转向环影响，先调节角度环的 `Kp`、`Kd`，使车体能够稳定保持直立。
2. 根据静止时 OLED 显示的 `GY` 值，修改 `平衡车/User/main.c` 中的 `GY -= 16`，补偿陀螺仪 Y 轴零漂。
3. 保持车体绝对竖直，修改 `AngleAcc += 0.5`，使显示角度接近 0 度。
4. 调整 `AnglePID.OutOffset`，补偿电机死区和机械摩擦。
5. 再逐步加入速度环，调整速度环参数以实现平稳的前进和后退。
6. 最后调节转向环参数，避免转向过冲或左右轮明显不一致。

也可通过连接到 USART2 的蓝牙模块在线调整参数。接收格式为方括号包裹、逗号分隔的 ASCII 数据：

```text
[slider,AngleKp,5.0]
[slider,SpeedKi,0.05]
[slider,TurnKp,4.0]
[slider,Offset,3.0]
[joystick,0,50,0,0]
```

可调参数名称包括 `AngleKp`、`AngleKi`、`AngleKd`、`SpeedKp`、`SpeedKi`、`SpeedKd`、`TurnKp`、`TurnKi`、`TurnKd` 和 `Offset`。

## 安全注意事项

- 平衡车启动时会快速输出电机控制量，请先悬空测试，再进行地面调试。
- 调整 PID 参数时从较小数值开始，避免高增益造成剧烈振荡。
- 电机供电与逻辑供电应具备足够的电流能力，并确保共地。
- NRF24L01 对电源纹波较敏感，建议在模块电源端做好去耦。
- 倾角保护仅在倾角超过 +/-50 度后停止电机，不能替代人工看护和机械安全措施。
